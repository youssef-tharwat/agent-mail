## Agent Mail v0.4.0

A simpler task-oriented CLI, native Claude delivery, and compiler-free installation.

### Install

```sh
brew install youssef-tharwat/tap/agent-mail
npx skills add youssef-tharwat/agent-mail --skill agent-mail -g
```

The agent skill is required in every participating client. Its installer uses
Node/npm; manual skill installation is covered in the user guide.

Or download the matching macOS/Linux archive below and verify its `.sha256` file.
ARM64 and x86-64 are supported. macOS requires 14+; Linux requires glibc 2.35+. The Herdr plugin now
uses the release binary too; users do not need Cargo.

### What's new

- Eight everyday command groups: `init`, `context`, `mail`, `task`, `participant`,
  `runtime`, `service`, and `status`.
- Group inference from verified identity or the sole configured group.
- Short replies without temporary files or separate reply keys.
- Task creation and updates are retry-safe using task identity and observed version.
- One atomic task update for changes and optional linked-request resolution.
- Claude Code's normal terminal uses its native inbox and lifecycle hooks for
  automatic attachment, recovery and confirmed delivery. No ACP or custom UI.
- Native Codex and Claude share durable delivery budgets and recovery semantics.
- Detach persists across startup hooks until explicitly enabled.
- Business deadlines are optional and separate from bounded delivery retries.
- Runtime configuration refuses to overwrite existing settings.

### Breaking CLI changes and migration

Old command spellings have been removed. Use `task` instead of `work`, `mail send`
instead of `send`, `mail list/show` instead of `inbox`, and `participant add`
instead of `register`. `work decide` and `work update` become `task update`.
`status --check` replaces `doctor`. Hook and bridge entry points move under `adapter`.

Stop Mail workers, back up the state directory, install the binary, and run
`agent-mail init YOUR_EXISTING_GROUP` to migrate through schema 12. Stored mail,
work records, identity bindings and history are preserved. Older binaries cannot
open the upgraded database. Regenerate runtime hooks and update the agent skill
and any scripts before restarting clients and the worker. Upgrade both ends of
an SSH relay before exchanging deadline-free messages.

See the [user guide](https://github.com/youssef-tharwat/agent-mail/blob/v0.4.0/docs/usage.md)
and [live acceptance evidence](https://github.com/youssef-tharwat/agent-mail/blob/v0.4.0/docs/native-inbox-acceptance.md).
Receiving an update does not prove task completion or acceptance. Remote live
acceptance remains separate from the local flow. macOS binaries are not notarized.
