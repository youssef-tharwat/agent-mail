# Agent Mail v0.11.2

Reduce the remaining background scan overhead with indexes for event
supersession, pending mail subjects, and attention subjects. The indexes match
the existing predicates, including exact text matching of record IDs.

## Validation

Repeated benchmarks on a consistent database snapshot returned identical
results before and after adding the indexes. Median query times fell from
120 ms to 3 ms for pending inboxes, 69 ms to 2 ms for attention checks across
80 registered mailboxes, and 346 ms to 6 ms for wake-event scans. These are
query benchmarks, not measurements of live worker CPU after deployment.

All 175 tests, strict Clippy, and formatting checks passed locally. Migration
coverage verifies unchanged events and receipts, foreign-key integrity, a
verified backup, and use of all three indexes. Release automation repeats full
validation and builds binaries for macOS and Linux on ARM64 and x86-64.

## Upgrade

Run `brew upgrade youssef-tharwat/tap/agent-mail`, or use the published native
archive or installer. Opening existing state with the new binary automatically
creates a verified backup, migrates to schema 23, and replaces the owned worker.
Tasks, messages, registrations, delivery policies, and retry budgets remain
intact. Schema 23 adds only indexes; older binaries cannot open the upgraded
store.
