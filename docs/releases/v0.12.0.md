# Agent Mail v0.12.0

Model interruptions now follow current reasons to act, with one delivery
reservation shared by native clients, Herdr, hooks, and model-facing watches.
Routine notices and receipt updates stay quiet. New final replies provide a
response without creating another request to acknowledge it.

## Changes

- Explicit request, notice, and response intents, with validated responder
  authority and relay capability negotiation. Existing messages and retry
  identities retain their recorded meaning.
- Typed group, participant, session, and delivery-consumer identities.
- Bounded attention batches, exact receipts, binding-generation checks,
  cancellation priority, and per-reason retry budgets. Native queue identities
  distinguish successive pages and recovery attempts.
- Explicit first-reply, any-settled, and all-settled waiting predicates. Responses
  satisfy reply predicates across local and relay delivery without implicitly
  settling the original request.
- Persisted GitHub PR merge facts tied to an expected full head commit. Other
  external waits remain visibly supervised by their responsible role.
- Removal of independent hook delivery budgets, raw model notification rendering,
  and Stop-hook continuations. Complete audit replay remains available.

## Validation

Migration, relay, waiting, delivery, hook, restart, and concurrency regression
coverage exercises the shared contract. Negative controls reproduced a native
queue-ID collision across attention pages and a missing relay reply link before
their fixes. Formatting, strict Clippy, and the complete test suite run locally
and in release automation on macOS and Linux, ARM64 and x86-64.

On a fixture with 20,000 requests, the indexed attention projection reduced
query time from about 24 ms to about 1 ms. This measures query latency; sustained
live worker CPU and model interruption rates depend on workload and consumer
adoption.

## Upgrade

Run `brew upgrade youssef-tharwat/tap/agent-mail`, or use the published installer
or native archive. Opening existing state creates a verified backup, migrates
to schema 24, and replaces the owned worker. Existing obligations and consumed
retry budgets survive the migration. Older binaries cannot open the upgraded
store.

Existing sessions refresh their recovery guide once. Replace raw audit watches
feeding a model with native delivery or `watch --attention --consumer NAME` and
its exact receipt contract. Load `agent-mail guide` for message intents and
explicit waiting predicates. See [the attention contract](../ATTENTION_CONTRACT.md)
for the behavioral and operational acceptance criteria.
