# Agent Mail v0.14.2

The bundled skill guide requires durable handoffs and verified live agent APIs,
forbids raw-pane fallback, and explains why old output does not prove agent
liveness. Transport regressions cover absent recipients, replacement sessions
and a guarded prompt refusal, preserving pending work without shell input or
false retrieval receipts. Coordination instructions consistently use independent
subtasks and writer-owned dependency plans.

The source includes the Herdr input guard and updated Herdr skill. The custom
macOS ARM64 companion build is `0.9.3-agent-input-guard.2`, distinguishable from
an official Herdr release. Typed input intent persists after agent exit; legacy
snapshots without known intent restore as unassigned and reject raw automation
until explicitly assigned. Deferred native agent resumes reserve input before
runtime attachment. Shell reuse requires an observed terminal identity and an
idle shell. Installing Agent Mail does not automatically replace Herdr.

The companion passed 3,758 native Rust tests and a real isolated handoff from
Herdr 0.9.1, preserving pane and shell process identity while rejecting raw input
both immediately after import and after agent exit. Its original maintenance
check limitation (old Apple Git) and Windows qualification scope are documented
in `integrations/herdr-input-guard/README.md`.

Agent Mail's runtime delivery behavior and schema remain unchanged (schema 27).
v0.14.1 publication was canceled during deployment preflight; its source tag is
retained, and this release contains the corrected companion patch.
