# Agent Mail v0.11.1

Reduce background service CPU use when many agents have event history. Per-agent
attention checks now use the recipient index instead of rebuilding the complete
wake-event view for every agent. The `doctor` command uses the same optimization.

## Validation

- Audited 25 related read queries for the same materialization pattern.
- Compared both changed queries across 80 registered mailboxes on a consistent
  database snapshot: results matched, including missing and stale bindings.
- Attention checks fell from 28.4 seconds to 0.090 seconds; diagnostic checks
  fell from 33.8 seconds to 0.087 seconds in that query benchmark.
- All 60 targeted reliability, delivery-verification, and follow-up tests passed,
  including empty-mailbox diagnostics. Formatting and whitespace checks passed.
- Release automation runs the full tests and strict Clippy checks before
  publishing binaries for macOS and Linux on ARM64 and x86-64.

## Upgrade

Run `brew upgrade youssef-tharwat/tap/agent-mail`, or use the published native
archive or installer. Restart the background service with the new binary to
apply the CPU fix. This patch adds no migration and preserves delivery policy,
retry budgets, tasks, messages, and registrations.
