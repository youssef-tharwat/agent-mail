# Agent Mail v0.9.1

Fixes Herdr delivery stalls tracked in [#1](https://github.com/youssef-tharwat/agent-mail/issues/1).

- New actionable mail and task revisions automatically receive a fresh bounded
  wake budget, preserving the five-minute cooldown. Retries survive worker restarts.
- Retrieval of visible mail and exact task revisions stops repeat notifications
  without resolving requests or making business decisions. Hidden pages and newer
  revisions remain eligible; partial retrieval cannot reset the same event budget.
- An operator alert does not block an eligible wake, including an interactive
  Herdr agent in the `done` state.
- Attention and `status --check NAME` expose current Herdr wake exhaustion and its
  repair action. Fresh events do not inherit older exhaustion diagnostics.
- README and the version-matched operating skill explain notification-driven
  coordination. Agents do not need inbox polling or per-message manual rearming.

Herdr remains optional. Codex and Claude native paths retain their existing
subscription, receipt and bounded retry behavior. Pause/prompt policy, identity
checks and explicit review decisions remain enforced. A retrieval receipt does
not replace the model's explicit delivery-check acknowledgment.

## Store migration

This release uses schema 17. For an existing store, back it up, stop its delivery
worker, and run `agent-mail init EXISTING_GROUP` using the upgraded binary before
restarting the worker through its usual supervisor. On macOS, `service uninstall`
preserves the database and `service install` restores the launchd worker. Stop any
foreground or Herdr-supervised worker too before migrating. Use the upgraded binary
for all agents and hooks; older binaries cannot read the migrated store.

Local validation: 110 tests passed, including isolated CLI pagination/restart,
legacy alerted inboxes, binding isolation, cooldowns, revision-scoped retrieval and
schema 16 migration. Strict Clippy and formatting checks passed. These were
isolated/fake-runtime tests; no production fleet or installed store was modified.
