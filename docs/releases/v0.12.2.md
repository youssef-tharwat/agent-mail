# Agent Mail v0.12.2

A retrieved request linked to a task now shares that task's follow-through
schedule when the request sender is the current task writer and its recipient is
the current owner. A blocked task or a checkpoint waiting for approval therefore
produces one decision escalation, without separate mail reminders asking its
owner to resume the same work.

Unread requests, explicit business deadlines, independent mail checkpoints and
different responsible parties retain independent schedules. Mail remains pending
until an explicit reply, resolution or withdrawal. Task closure and reassignment
do not silently settle requests. Mail details identify the governing task and
revision; status counts shared requests while showing each independent schedule
once. Superseded mail occurrences become inactive immediately, and invalid batch
reservations release newer attention without waiting for their five-minute expiry.

Verification failures now appear in worker status and stderr with bounded details.
Delivery diagnostics separate writer acquisition, transaction holding and runtime
I/O, distinguish completed, failed and abandoned work, and add no database writes.
An actual slow-runtime regression demonstrates that unrelated writers are blocked
while a delivery holds its SQLite transaction, including cancellation cleanup.
These measurements expose the contention; this release preserves the transaction
guards against endpoint, identity, source and policy races.

Opening an existing store upgrades it to schema 25 with a verified backup and
replaces the owned worker. Existing messages, dispositions, registrations,
attempts, receipts and checkpoint history are preserved. Active clients receive
the updated scheduling guide once on their next input hook; recovery metadata is
refreshed without resetting notification budgets.

Lifecycle regressions cover blocked tasks, dependency readiness, independent
requests, stale reservations, reassignment, restart and migration from schema 24.
The blocked-task and checkpoint regressions fail on the previous published code;
the stale-reservation regression also fails when only its validity guard is removed.
Formatting, strict Clippy and the full suite run on macOS and Linux, ARM64 and x86-64.

Upgrade through Homebrew or the published installer/native archive.
