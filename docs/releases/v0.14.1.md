# Agent Mail v0.14.1

Stopped-agent handoffs retain their pending task and mail. The bundled guide now
requires durable Mail and verified live agent APIs, forbids raw-pane fallback,
and explains why old terminal output is not evidence of a running agent.
Transport regressions cover absent recipients, replacement native sessions and
an agent.prompt refusal after live preflight, including absence of shell input
and false retrieval receipts.

The source includes a companion Herdr patch with typed, persistent agent/terminal
input targets. Agent terminals reject raw automation input after exit until an
explicit, terminal-identity-checked release. The custom macOS ARM64 Herdr build
is published separately as `0.9.3-agent-input-guard.1`; it is not an official
Herdr release, and installing Agent Mail does not automatically install it.
See `integrations/herdr-input-guard/README.md` for its source revision, build
instructions, contract and verification limits.

The coordination audit guide now consistently uses writer-owned dependency
plans and independent subtasks, removing stale generic dependency-link advice.
This is a documentation and regression-coverage release for Agent Mail; its
runtime delivery behavior and schema remain unchanged (schema 27).
