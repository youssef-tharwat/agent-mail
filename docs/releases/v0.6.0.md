# Agent Mail v0.6.0

Durable task coordination with a bundled operating guide, automatic local Codex
attachment, and typed lifecycle states.

## Install

```sh
brew install youssef-tharwat/tap/agent-mail
# Existing installation: brew update && brew upgrade youssef-tharwat/tap/agent-mail
agent-mail --skill
```

Native binaries are available for macOS and Linux, ARM64 and x86-64. No Cargo or
npm is required. Herdr remains optional: `herdr plugin install youssef-tharwat/agent-mail`.

## Changes

- The binary bundles the required skill. Startup/reset hooks supply complete
  operating flows; routine updates supply bounded state without repeating the guide.
- Interactive Codex launches own a private app-server and attach the sole loaded
  thread automatically, including resume. Native permissions and hook trust remain
  in effect. Claude keeps its native inbox and additive hook integration.
- Diagnostics distinguish configured launches from observed hooks, scoped to the
  current launch and identity. Hook execution does not prove model consumption.
- Tasks use `open`, `ready`, `active`, `blocked`, `review`, `done`, `accepted`, or
  `cancelled`. The last three close the assignment automatically. The writer
  chooses transitions and applies the workflow's evidence rules.
- Message, event, identity, runtime, hook and delivery states use typed enums.
  Delivery status codes have a separate optional diagnostic detail field.
- Updated usage documentation, README demo, and assignment/review/correction flows.

## Breaking changes and upgrade

Stop the service and clients and back up the state directory before upgrading.
Run `agent-mail init YOUR_EXISTING_GROUP` with the new binary, then restart them.
Schema 14 validates task records, history, snapshots and stored retry results.
Unknown legacy states or contradictory state/open values abort the migration;
resolve their meaning explicitly in a backed-up copy before retrying.

Writable `open`, `--close` and `--reopen` are removed. Use a terminal state to
close a task and an actionable state to reopen it. Accepted revisions and evidence
remain explicit. Task closure does not resolve unrelated pending mail. Do not
replay old update documents after changing their content; inspect the saved result
and current version before issuing a new decision. Upgrade relay peers together.

The bundled skill is matched to the binary; separate skill installation is no
longer required for managed launches. Remove older manually installed Mail hooks
before adopting managed launches to avoid duplicate hooks.

## Verification and scope

Local validation passed 77 tests plus one doctest, strict Clippy and formatting.
The live mixed Codex/Claude engineering cycle and its limitations are recorded in
[managed launch acceptance](https://github.com/youssef-tharwat/agent-mail/blob/v0.6.0/docs/native-launch-acceptance.md). A separate isolated
CLI flow verified assignment, blockers, review, correction, acceptance and replies.

The delivery service still needs to be started explicitly. ACP, hosted services
and typed resource attachments are not part of this release; tasks retain evidence
references. Remote SSH acceptance remains deferred.
