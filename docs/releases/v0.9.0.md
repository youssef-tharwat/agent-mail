# Agent Mail v0.9.0

- `watch` streams bounded batches of task changes and incoming mail over the local
  socket. Identity-scoped cursors support durable resume and replay after a worker
  restart.
- `mail wait ID` waits without client polling for the first reply, all recipients
  to settle, or a request deadline/optional timeout. Waiting never resolves mail
  or changes a task.
- Native and Herdr notifications group changed IDs instead of repeating full
  recovery context. Startup/reset recovery stays bounded; details are fetched on demand.
- Herdr binding validates the explicitly selected pane and gives actionable
  identity diagnostics. Same-pane Codex binding and authentication reject a
  disagreement between `CODEX_SESSION_ID` and Herdr's native session report.
- The README and version-matched skill explain standalone setup, a dedicated group
  for each project/fleet, coordinator versus worker setup, and safe delivery repair.

No database migration is required beyond v0.8.0's schema 16. Herdr remains optional;
existing Herdr prompt policy remains explicit. Automated tests cover replay,
reconnection, cursor isolation, reply races, fanout settlement, and timeout behavior.
The current Codex pane's live identity mismatch is rejected rather than repaired
implicitly; an equivalent Claude mismatch has not been reproduced.

The bounded Herdr reminder-budget limitation tracked in
[#1](https://github.com/youssef-tharwat/agent-mail/issues/1) remains open.
